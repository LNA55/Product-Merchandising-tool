Merch mix versions

Every saved state of the weighting matrix is a merchandising mix version. Versions are immutable — a new incremental version is generated at every save, because the version name is a unique ID linked to the impact tests.

Naming convention

The unit is a published value; decimals after the dot are internal drafts never published.
V0.4 = 4th draft version · V1.0 = first published version.
Publishing the last draft Vn.X creates V(n+1).0 — both are kept, and the description of V(n+1).0 notes that it equals Vn.X.

Impact Estimation & Impact Analysis

Run Impact Estimation (pre-launch) projects the expected impact of a mix version before it goes live. For published versions, the feedback compares the post-launch Impact Analysis to the pre-launch Impact Estimation.
These analyses are not computed by this tool: they run in an external, integrated tool, and the results are sent back here.
