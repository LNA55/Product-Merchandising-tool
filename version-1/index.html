Merchandising mix control

Control center of the merchandising tool: the rows are the available data feeds, the columns are the merch anchor points of the e-commerce site. Each cell holds the weight (0–10) of that data source in determining which products are shown to the final customer in that block.

Version naming convention — the unit is a published value; decimals are internal drafts never published. V0.4 = 4th draft version; V1.0 = first published version. Publishing the last draft of Vn.X creates V(n+1).0 — both are kept, and the description of V(n+1).0 notes that it equals Vn.X. A saved version is immutable: every save generates a new incremental version, because the version name is a unique ID linked to the impact tests. See Merch mix versions.
