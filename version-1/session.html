What “session” means in these data

Everywhere the word session appears in this tool — in KPI definitions, in the session browsing data feeds — it refers to the definition below, not to a classic web-analytics session.

Logged-in user

The “session” is the rolling 48-hour accumulation of all this user's sessions, across all devices. If a customer browses on mobile in the morning and comes back on desktop in the evening, both count as the same session for these data — as long as they fall within the rolling 48-hour window.

Anonymous visitor (not logged in)

The “session” is a single session tracked by cookies, on that one browser and device. No cross-device merging is possible without a login.

Where it applies

  • The Session browsing data feeds (recently viewed, already in your cart, similar to the most recently viewed product…): their scope is the current session, including logged sessions of the past 48 hours.
  • The Add to cart attributed KPI: clicks and add-to-carts are matched within the same session as defined here.
Note — this definition, and therefore its parameters (48-hour window, cross-device merging, cookie scope), can be modified. The tool does not offer this setting for now.
